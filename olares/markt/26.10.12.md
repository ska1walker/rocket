# A rare loading error fixed
v26.10.12: Now and then a page reported an error while loading ("Hydration failed"). The cause was a marker that Next.js inserts for the app icons and removes again — but only when it does not happen to fall on the border between two pieces of the page as it is sent. Rocket now links its icons itself, so the marker no longer exists. The icons look the same as before. No database changes.

## Deutsch
v26.10.12: Ab und zu meldete eine Seite beim Laden einen Fehler („Hydration failed“).
