# common shell, tab icon
v26.10.7: Rocket follows the shell every AImighty app now shares. Page titles are larger, every button has the same corner radius (the Create button in the top bar was squarer than the rest), and the selected entry in the sidebar is a tinted row instead of gold text alone, so it can no longer be mistaken for the keyboard focus. The browser tab shows only the rocket, in a gold that suits light and dark tab bars, and names the page first („Firmen · Rocket“), so several open tabs can be told apart. Every button that carries only an icon shows its name on hover. On the start page, an overdue task shows a clock next to the word. No database changes.

## Deutsch
v26.10.7: Rocket folgt dem Grundgerüst, das jetzt alle AImighty-Apps teilen. Seitentitel sind größer, jeder Knopf hat dieselbe Rundung (der Knopf „Erstellen“ oben war eckiger als der Rest), und der gewählte Eintrag in der Seitenleiste ist eine getönte Zeile statt nur goldener Schrift, damit er nicht mehr wie der Tastaturfokus aussieht. Im Browser-Tab steht nur noch die Rakete, in einem Gold, das auf hellen und dunklen Leisten trägt, und zuerst der Seitenname („Firmen · Rocket“), damit sich mehrere offene Tabs unterscheiden lassen. Jeder Knopf, der nur ein Zeichen trägt, nennt beim Überfahren seinen Namen. Auf der Startseite zeigt eine überfällige Aufgabe eine Uhr neben dem Wort. Keine Datenbankänderung.
